# Parches de compatibilidad — 27 de octubre de 2026

Genkit 1.43.0 sigue declarando Zod3 y OpenTelemetry1/SDK0.52. Sustituir todo por Zod4/OTel2 rompe contratos internos, incluido Resource. Se conservan las APIs existentes con parches reproducibles `pnpm patchedDependencies`, sin editar node_modules manualmente.

- Zod3.25.28: abortar arrays con max/length excedido y sets con max/size excedido antes de recorrer elementos, tanto CommonJS como ESM. Adaptación del principio de la corrección upstream de Zod4: https://github.com/colinhacks/zod/commit/a0ebf970f2d752e5f58527cd2942ff48be4f46bd . Zod3 no ofrece límites max/size para Map. Este backport cubre la API v3 usada por esta aplicación y Genkit; no certifica los exports beta v4 incluidos en ese paquete.
- Los consumidores de Zod4 usan 4.6.7, incluido `eslint-plugin-react-hooks`, que importa `zod/v4`. Las versiones estables v4 se prueban junto al backport v3; no se usa el export beta v4 del paquete v3 para ESLint. Sharp permanece fijado en 0.35.5.
- OpenTelemetry core1.25.1/1.30.1: acotar baggage antes de join/split/decodificación (8192 unidades de texto, hasta180 cabeceras); descartar entradas no textuales o sobredimensionadas. Se modifican los tres builds JS distribuidos; las cabeceras ordinarias conservan su comportamiento.
- Jaeger2.9.0 y siete instrumentaciones de bases de datos se actualizan a versiones corregidas. Se conserva la cohorte del SDK y se comprueban los contratos reales de inicialización/registro/cierre.

Ejecutar `pnpm install --frozen-lockfile`, `pnpm run test:security`, `pnpm test`, `pnpm typecheck` y `pnpm lint`. La prueba de seguridad consulta únicamente el árbol instalado, prueba límites de colecciones/cabeceras, el propagador Jaeger, inicializa/cierra el SDK y ejecuta un flujo Genkit determinista sin plugin/modelo ni exportador de red. El lockfile exige los parches y falla si no se aplican. Los parches nativos de pnpm reemplazan los archivos y el postinstall de patch-package; sus hunks de seguridad son equivalentes, incluida cada copia de core 1.30.1.

`pnpm audit --prod --json` sigue avisando por las versiones originales de Zod/core; esos avisos no se suprimen. Mantener los parches bajo revisión, y retirarlos únicamente cuando Genkit permita una migración comprobada a las versiones upstream corregidas. La compilación completa tiene un bloqueo previo de acceso Firestore durante prerender, documentado fuera de este repositorio en el informe de auditoría; no se relajó ese control ni se desplegó el servicio.
